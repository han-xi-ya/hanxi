差异点图例（①—⑥ 与盘上角标对应，逐条拍板见 PLAN_N40_WHEEL_SKIN.md §2）

  1. ① 扇区间隙 —— 现状：名义缝 0.9° + 发丝描边"一镜到底"连续玻璃盘；提案：缝角 ≈4.2°（外缘 ≈12px）+ 楔形端头圆角化，八枚成为独立"弧段花瓣"，盘缘留连续亮环。
  2. ② 帽带圆角 —— 现状：帽带底环+子扇区全部直角楔形（r174→236）；提案：子扇区大圆角厚弧段，底环两端收圆帽，级联"生长感"替代"贴纸感"。
  3. ③ 图标座 —— 现状：图标井 = --surface-panel 底 + 1px 边框（暗色下换 surface-hover）；提案：磨砂浮起座（明：白面高光渐变 / 暗：frost 半透），悬停时主色描边 + 主色软底。
  4. ④ 名称排版 —— 现状：两行折行截断、10–12px 随密度档；提案：单行 12px + 全称职责完全交 hub 读数，扇区只留短名，视觉重心归图标。
  5. ⑤ 悬停顶出（静帧） —— 现状：径向外顶 4px + primary-soft 填充 + 盘缘高亮弧；提案：外顶 8px + 主色辉光投影，其余扇区整体降透明度，"选中块拿起、全场让位"。
  6. ⑥ 圆心 hub 读数区 —— 现状：panel 面 + 虚线环 + 名/型/提示三行文字；提案：hub 升级为"仪表核"——读数 + 类型胶囊 + 8 枚槽位刻度环(点亮当前槽) + 常驻"点按中心收起"提示。

样张口径提醒：提案盘背后的彩色底纹仅为演示"磨砂半透"效果（真实窗口下即桌面内容），最终观感依赖真机 WebView2 的 backdrop-filter 表现； 角标数字、引线为样张注释，不会出现在产品里。现状盘的圆心虚线环(hub-ring)、盘缘刻度线(ticks)在提案中被 ⑥ 的槽位刻度环取代。
