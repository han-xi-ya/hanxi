# N6 桌面留言板 UI 重设计方案（机主已拍板 2026-09-23）

> 机主原话：「桌面留言板这个UI设计的不喜欢。不友好。」三问拍板：
> ①牌面=**便利贴大卡片**；②快捷=**表情类型一键挂**；③管理页=**彻底改版**。
> 后端契约**零改动**（挂牌正文天然多行：第一行=主题大字、其余行=副行小字；
> 表情就是正文首字符，无需新字段）。

## 病根诊断（对症改，不空谈"美观"）

| # | 病灶 | 改法 |
|---|---|---|
| 1 | 全屏黑板 + 大字 = "停电/死机"观感，离岗告示不像告示像故障 | 屏幕中央便利贴大卡（微旋转+胶带条+纸黄底），背景只留轻微压暗——像"贴了张条" |
| 2 | 牌上印着「点击任意处或按 Esc 撤牌 · 挂出期间屏幕保持常亮」——给旁观同事看不懂的操作性废话 | 撤牌提示自动淡出（前 5 秒可见、之后只剩角落小 Esc 角标）；防休眠说明移回管理页 |
| 3 | 挂牌动线三步（填字→保存→挂牌），高频低频混排 | 表情类型钮**点一下即填词、双击直接挂出**；「立即挂牌」大钮常驻 |
| 4 | 挂出去不知道牌长什么样，字号合不合适靠猜 | 管理页右侧**实时便利贴预览**（与挂牌同一 BoardCard 组件按 scale 缩——所见即所得由组件同源保证，不是第二套画） |
| 5 | 状态 chip 仪表盘（已挂牌/热键在位/防休眠）聒噪 | 头章只留「未挂牌/已挂牌」+ 异常态才出现的警示 chip |
| 6 | 预设 chip 行与说明文字挤在一起 | 预设升级为 7 枚可视类型钮（🤝开会/🍜吃饭/☕茶水/🚶小憩/🚻卫生间/🏠下班/⚠️别动我电脑），副行自带回时 |
| 7 | 字号/目标屏/热键低频设置占版面 | 收进「高级设置」折叠区；热键未在位等异常自动展开并警示 |

## 结构与文件

- 新增 `components/msgboard/BoardCard.vue`：牌面唯一画法（popup 与管理页预览共用，
  props: text/fontSize/scale）；第一行=标题（fontSize 直用），其余行=副行（×0.42）。
- `MsgBoardView.vue` 彻底改版：编辑列（类型钮网格→正文框→立即挂牌/保存）+
  预览列（sticky 右侧）+ 高级设置折叠；数据流（pullAll/dirty/回读校正）原样保留。
- `MsgBoardPopup.vue` 重绘：压暗层 + BoardCard + 自动淡出提示；交互（点击/Esc/
  热更事件/防休眠登记）一字不动。
- 后端与事件契约零变更 → bindings 不重生成、Go 测试不动。

## 兼容与诚实边界

- 旧配置的自定义正文（含后端 4 条老预设文本）照常渲染：无表情就是纯文字便利贴；
- 正文 400 字上限、字号 24–200 钳位等后端闸口原样（预览区溢出裁剪与牌面同规则，
  不假装"放得下"）；
- 双击即挂 = 点选类型后静默 save+toggle，失败（如热键闸）走既有错误横幅，
  成功即牌已挂出并自动进入已挂牌态。
