## 1. 改进批次（v2 重写：2026-09-23 机主亲选八痛点，v1 的触发键/排除清单方向作废）

> 机主勾选：牌面「字多看不清 / 不知道选没选中 / 分组展开很意外 / 样子不好看」
> + 配置「要跳另一页改 / 改完看不到盘 / 排序上格麻烦 / 12 格限制分组乱」。
> 定性：轮盘的**界面与配置体验整体重做**，触发手法不在本轮范围。

### 牌面组（QuickMenuPopup）

- **F1 可读性**：扇区改"图标主角"制——图标 18→26px，名称单行省略号截断，
  字号随条目数自适应（≤6 大一档 / 7-9 标准 / 10-12 缩至 11px）；完整名称
  与类型统一进 hub 大字号读数（hub 本来就是给操作者看的读数区，让它干活）。
- **F2 选中反馈**：悬停扇区三重反馈——底色提亮 + 沿半径外扩 4px + 描边高亮；
  hub 同步显示「选中项名 + 类型徽标」；未悬停回到盘标题。现在只有轻微变色
  即"不知道选没选中"的病根。
- **F3 分组可预期**：分组扇区右上角常挂 ▸ 角标 + 子条目数徽标；悬停时 hub
  副行提示「松手展开/点击钉住」；子环展开加 120ms 缩放淡入与父扇区连接线，
  "突然多一圈"变成"看得见长出来的"。
- **F4 盘皮重绘**：从"色块拼图"改"玻璃底盘"语言——连续底盘 + 扇区间细缝、
  盘缘高光环、外投影；配色全部走工作台 token（明/暗主题自动跟）；图标收进
  统一圆形承托座。与 F1-F3 同一次绘制层重构落地，不单独刷皮。

### 配置组（QuickMenuView 主场化）

- **C1 就地编辑**：把「设置→托盘菜单」的条目编辑器抽成共享组件
  （TrayItemsEditor），轮盘模块页内嵌同一组件——**一处编辑两处生效**（数据
  本就同源），设置页保留入口并在轮盘页明示"与托盘菜单共用"。消灭跳页。
- **C2 实时预览**：轮盘页右侧嵌一个**可交互的静态盘预览**（新共享组件
  WheelFace：Popup 与预览同一绘制核心，预览随勾选/顺序即时重排；Popup 保留
  交互层）。"勾了哪个上哪个盘"直接看见。
- **C3 点上格换位**：预览盘支持点击扇区 → 高亮编辑列表对应行并滚动到位；
  行内提供「⇄ 与选中格互换」直调按钮（列表行×目标扇区互换，不做拖拽——
  拖拽进 SVG 的命中与滚动边界坑多，互换按钮覆盖"放到顺手方位"的真实诉求）。
- **C4 容量与分组治理**：主盘推荐 ≤8 的软提示（超出时预览边缘黄字警示，不
  禁止）；分组子环沿用 8 项上限 + 截断提示（已有）；文案纠正"12 格"误解——
  扇区数=条目数自适应，说明页写清"条目越多格子越窄，建议分组收纳"。

### 保留项（v1 方案中仍然成立、但降档为后续候选）

- 触发键可配置（中/侧键直按）与应用排除清单：真痛点但**非本轮机主所选**，
  归档为 N5b 候选，牌面/配置重做验收后再议。

### 跨语言几何锁（v1 B3 原样保留）

  预览引用"——补一枚 Go/前端双端快照一致性测试结清 #50 尾巴。
