# 内嵌终端 v0 —— 机主真机验收清单

> 生产构建后逐雷走查。三雷各一屏；每雷末尾给"过/不过"判据。
> 单元/构建门禁已绿（spec 26 用例、vue-tsc 0 错、vite build 成功），
> 但 **压缩管线相关的一切只有真机能判**——这三雷就是为盲区配的。

## 预备：起生产包，接入一条会话

1. `task build APP_NAME=hanxi-new`（或现有出包路径），启动产物。
2. 侧栏「开发者工具」→ 内嵌终端 → 新建 ▾ → PowerShell。
3. 判据基线：状态条走到「显示通道在线」，芯片「已连接」，能 `ipconfig` 回显。
   （连不上先记下状态条原文——"握手超时"是前端问题，"传输层报错"多半是后端/装配问题。）

## 雷① —— vim / DCS：生产构建再压缩回归（xtermjs/xterm.js#5800 病灶）

⚠️ 背景一句话：xterm 6.0.0 出厂即预压缩 ESM，构建链再压一轮历史上会毁 requestMode
闭包。本仓 Vite 8.3.4 已是 rolldown/oxc 管线，`esbuild:{minifyIdentifiers:false}`
护栏在 Vite 8 下**实测不生效**（详见 vite.config.ts 注释与施工报告）——oxc 是
AST 级改名、理论安全，但"理论"二字只有真机说了算。**此雷红了 = 优先怀疑压缩链，
对照实验：`vite build --minify false` 出一份开发态包同屏复测。**

- [ ] 1. 会话里跑 `vim`（没有 vim 就 `git log` 进分页器代替）；
- [ ] 2. `i` 进插入模式打一行中文 → `Esc` → `:wq` 退出——每步画面即时跟随、无残帧错位；
- [ ] 3. 拖动应用窗口改变大小：vim 重排不留花屏块，回终端后 `ls` 提示行对齐；
- [ ] 4. DCS 直喂：PowerShell 执行
      `[Console]::Write([char]27 + 'P0;1;123q' + [char]27 + [char]92)`
      （一串 DCS 垃圾帧）——渲染器不炸、通道不断（状态条仍「已连接」）；
- [ ] 5. 光标位置类探针：`powershell -NoProfile -Command "[Console]::Write([char]27+'[6n')"`
      换到 cmd 档跑裸 `echo`（若 cmd 下无回显属正常——requestMode 探针主要看 vim 场景）。
- **过**：以上任一条出现"模式应答错乱/卡死/整页白屏/通道断流"即**不过**，
  截图状态条 + 复现步回传，先做 `--minify false` 对照再定性。

## 雷② —— `yes | cat` 吞吐与回显延迟

- [ ] 1. PowerShell 档执行 `(1..200000 | ForEach-Object { 'y' }) -join [Environment]::NewLine`
      （Windows 无 coreutils `yes`，这等价于 20 万行连灌）；灌期间直接看滚动是否跟手、
      界面（chips/侧栏/悬停）还可交互，滚轮可上翻旧行；
- [ ] 2. 同屏另起 cmd 档跑 `cmd /c "for /L %i in (1,1,30000) do @echo y"`，
      输出狂泻时用鼠标点侧栏别的模块再切回来——**切走进程还活（名录里芯片仍「运行中」），
      切回重新接入只见新输出、旧断口无假象**（v0：断线期间输出不补）；
- [ ] 3. 延迟手感：输出泻完后立刻敲 `ping 127.0.0.1` 回车，回显应在肉眼即时档
      （>300ms 明显黏手记为不过）；`Ctrl+C` 中断仍灵敏。
- **过**：无整窗卡死 >2s、无字节错序（行不乱串）、Ctrl+C 有效即过。
  bufferedAmount 背压未做（v0 如实），若发现巨量输出把 webview 打挂，把行数与现象回传。

## 雷③ —— 微软拼音连打 / Ctrl 组合键 / ESC 与候选窗位置

- [ ] 1. 输入法切**微软拼音**，命令行连打一串拼音（如 `xiexielaishile`）快速上屏中文：
      候选窗应**贴在光标处**（xterm 隐藏 IME textarea 锚定光标），不钉死窗口左上角；
      连打中途不按任何键——上屏文本与原输入一致、无丢字重字；
- [ ] 2. 组合期回车：候选窗开着时按 `Enter` 应只确认候选词、**不得**向 pty 发 CR
      （看下一行是否莫名出现提示符重绘即可判定）；用数字键/空格选词各试一次；
- [ ] 3. Ctrl 组合键：`Ctrl+C` 中断前台进程生效；`Ctrl+A/Ctrl+E/Ctrl+W` 在 PowerShell
      PSReadLine 下应如原生终端动作；**`Ctrl+F` 是有意劫持给页内搜索**（不再下发
      0x06 前移光标——v0 取舍，验搜索条弹出/Esc 收起/Enter 下一处命中三件事即可）；
- [ ] 4. `Esc` 单键：跑 `vim` 进出插入模式用 Esc 回普通模式**不应**有 >100ms 的
      迟滞（xterm 等待序列前缀的经典黏性，若明显"Esc 后顿一下"记入报告，不判死）；
- [ ] 5. 候选窗跟随：滚轮上翻旧输出停在中间时开始连打——候选窗仍在**输入光标**处而非
      视口边缘；选词上屏后画面回到底部跟最新。
- **过**：1/2/5 全对、3 全对（含 Ctrl+F 搜索）、4 无明显迟滞即过；
  任一项不过，记「输入法版本 + 档位(cmd/powershell) + 步号」回传。
