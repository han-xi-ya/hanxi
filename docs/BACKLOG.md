### 1.1 卡内高亮存档（无独立 PLAN、仅存本档的裁决与侦查结论）

- **F5 官方通道侦查（2026-09-17 实测）**：微信官方更新页 `weixin.qq.com/updates?platform=windows` 为 SSR，正则 `WeChatWin_([0-9.\d]+)\.exe` 一发命中版本号+直链双结果（`dldir1v6.qq.com` 系 universal 包）；页内 `8.0.x` 系列是移动端勿混；HTML 抓取非结构化 API，解析失败必须优雅降级为"拉起浏览器打开该页 + 显示本机版本"，不猜不编。数据目录认两代：3.x `Documents\WeChat Files` 与 4.0（Weixin）`xwechat_files`，用户可自定义盘符。副产品红利：直链可支撑"复制下载地址/浏览器直接下载"（该能力已随 N38 `b4591e1`「下载安装包」兑现）。
- **F7 分发策略（写死防改口）**：paddle 引擎 zip **可进公开 Release 当引流品**（Apache-2.0 模型 LICENSE/NOTICE 随件、ORT MIT、VC 运行时 app-local），公开前三道闸：验货（无腾讯件夹带）/署名（声明"引擎 PP-OCRv6，与微信无涉"）/背书（挂 hanxi 名即负责任）；**wechat 引擎 zip 永远私发**，与 hanxi 本体"公开安装包+私发组件"分界同构。
- **F6 四条裁定（2026-09-17 用户拍板，`internal/settings/paths.go` 包注释点名的即本条）**：① 单 exe 跑起来就在 exe 同级自动创建 `hanxidata/` 并落数据；② 不再使用 `%APPDATA%\Hanxi`；③ 旧 `data/` 便携兼容正式废弃（零识别）；④ 支持数据目录绑定——有绑定声明就认绑定，没有就落同级（"绑定哪个用哪个"）。
- **F6 模式消亡宣告（写死防复活）**："绿色免安装 / Portable"自 F6 起**不再是一种模式、不再是一个特性、不再有单独排期项**——同级 `hanxidata/` + `hanxi.bind` 是唯一存在方式；旧标准模式的价值由显式绑定承接，永远"用户说了算、无静默路径"。定稿见 `PLAN_PATHS.md`。
- **F7 形态升级裁定**：hanxi-ocr 自"引用式"（挪走原件即断线）升为"托管式"（双 zip 拖入 `versions/`，与托管家族同族同规）——`internal/modules/ocr/models.go`/`hosted.go` 注释点名的即本条与上条三闸。
- **F8 设计边界（MVP 克制版，`internal/modules/msgboard` 包注释点名于此）**：预设几条 + 自定义文字字号 + 热键/轮盘/托盘三通道 + 副屏跟随；**不做**倒计时自动摘、日历联动、密码锁屏（隐私向一律不碰）；挂牌期间 KeepAwake 引用计数持有、摘牌即释放，不写死常开。
