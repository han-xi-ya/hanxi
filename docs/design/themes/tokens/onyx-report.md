# onyx · 曜石 —— 单套深化审查报告（v2.1）

> 对象：[`onyx.css`](onyx.css)（起点为 `preview.html` 的 `[data-accent="onyx"]` 两块）。
> 全部数值为 sRGB WCAG 2.x 相对亮度实算（与 `gen-palettes-v2.mjs` 同一算法），
> 感知台阶为 OKLab L 值；微型自检预览见 [`onyx-check.html`](onyx-check.html)（浏览器打开即实时复算下表配对）。

## 1. 契约与标准

- 覆写变量集 = 其余色板集合 + 8 枚状态色（浅 27 枚 / 深 25 枚），与 `tokens.css` 变量名完全一致；
- AAA 验收线：正文/面板≥7 · 辅助/面板≥7 · 弱注/面板≥4.5 · 按钮字/主色≥7 · 主色链接/面板≥7 · 正文/选中≥7 · 状态字/状态软底≥4.5；
- 附加自设线（onyx 招牌，README v2 口径）：状态字/软底≥**5**、主色链接于画布/柔面≥7、边框≥3:1 非文；
- 感知台阶：page→panel→soft→hover→selected 逐级 OKLCH ΔL≥0.02；
- 深模式 page 底允许近纯黑（L≤0.16，OLED 合理）——本板 page L=0.127，合规。

## 5. 五个专属审查点的结论

1. **浅边框过重**：`#64748b`(4.76:1) → `#838f9d`。面板上 3.29、画布上 3.05，落在任务给的 3.0–3.5 目标带内；满屏表格线从"铁栏"降为"蓝图细线"。代价：落在柔面行上仅 2.93、悬停行上 2.64（非文，见风险 2）。
2. **浅三级文字层次**：旧 muted `#333c46`(L.352) 与 subtle `#4c5763`(L.452) ΔL 仅 0.100；subtle 提亮至 `#626b77`(L.524)，ΔL 拉到 **0.172**，text/muted/subtle 呈 .166/.352/.524 均匀三级。subtle 面板上 5.40 满足契约 4.5（AAA 全字级 7 只压给正文与辅助字，这正是三级层次得以拉开的前提）。
3. **information 与主色同蓝**：浅板从"逐字节相同"改为 `#1c6b92`（OKLCH h235 vs h261，Δh≈26°，ΔL+.055，互比 1.34）；深板改 `#66cbec`（h222，Δh 31°）。chip（软底小片）与链接/按钮同屏时以色相+底色双线索区分；信息语义由"更深更灰的天蓝→亮青"仍属蓝系冷色，不与正/警/危撞。
4. **深选中行上的四枚 chip**：契约内（字/软底）四色 7.86–9.85 全部富余；实际风险在**裸放状态字**——旧 `#2b4a73` 上 danger 4.10、information 4.31 低于 4.5，selected 压深为 `#244268` 后四色 5.68/5.51/6.52/4.88 全部达标，且四枚软底以 ≥1.46:1 + 色相从选中行浮出。正文/选中 9.42（旧 8.31）。
5. **浅状态软底"医疗表单感"**：四枚 soft 统一至 L≈.945、彩度 0.018–0.028（旧 0.027–0.040），如 `#dfe9fb`→`#e1f1f9`、`#f7e9cd`→`#f3edd8`；大块 KPI 同屏时只剩"纸上一缕淡晕"，靠文字色承担全部语义。chip 字/软底最低 5.09（信息位），不破 5。

## 7. 遗留风险与待拍板

1. **主色变深**：`#0b4fc0→#0649b8` 让浅模式按钮比 preview 稿沉半档，"亮眼"属性进一步让位于无障碍职能位；若评审坚持 preview 观感，回退代价是主链接在画布上掉回 6.88（<7，契约外但同屏可见）。
2. **边框在非面板底上跌破 3:1**：`#838f9d` 于柔面 2.93、悬停行 2.64。表格线画在 soft/hover 行上属"装饰性分隔"（行内容仍以文字对比为准），非严格违规；若评审要求全表面 ≥3，唯一解是把边框提回 `#7d8a99` 一线，浅模式吵度回升。
3. **`--state-*-glow` 未覆写**（契约只含 8 枚状态色）：信息光晕仍为基础值 `rgba(37,99,235,.15)`，与新信息主色 `#1c6b92/#66cbec` 在 chip 圆点发光场景下色相略有出入。建议落地时一并覆写或接受 15% 透明度的低敏感偏差。
4. **深模式弱注记/选中行 3.62、辅助字/选中行 5.78**：均不在契约内（契约只锚定正文/选中），但列表选中行放 metadata 时达不到 AAA——视图层应在选中行内改用 `--color-text`。
5. **danger 裸字/选中 4.88** 余量最薄（0.38），任何后续微调（如 selected 再压深）需复算。
6. **information 换蓝为青**改变了 v1 时代"信息蓝=通用蓝"的用户记忆；onyx 本就是例外板，但若最终产品同时上架 sky（azure 主色），onyx 的信息青与 sky 的 azure 观感距离需真机并排复核（`onyx-check.html` 可并看）。
7. 终端块、`--overlay-mask`、深模式阴影继续吃 `tokens.css` 基础值（既有决策，不随色板反相）。
